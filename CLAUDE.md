# Repo rules for Claude

- Never include a Claude session URL (e.g. `claude.ai/code/session_...`) in
  any commit message, PR title/body, PR comment, or issue comment in this
  repo. This is a public repo — session links do not belong in its history.
  The generic attribution footer (`_Generated by [Claude Code](https://claude.ai/code)_`
  with no session id, and no `Claude-Session:` trailer) is the most that
  should ever appear, and only where an attribution footer is actually
  required.
